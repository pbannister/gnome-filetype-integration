# Record: Why tab

## Outcome

The main window now has four tabs: **Installed**, **Relevant**, **About**, and
**Why**.

The Why tab contains, open rather than collapsed:

- **How this file was identified** — the source and confidence, libmagic result,
  extension mapping, category, path, and every identification reason.
- **Command line** — `filetype identify --apps`, `filetype apps`,
  `filetype open`, and `filetype identify --json`, each with a Copy button.
- **Notes** — the existing recommendation notes, when present.

The details and command sections no longer take space from the application
lists, and they no longer need an expander. The file card, warnings, and footer
actions stay outside the tabs.
